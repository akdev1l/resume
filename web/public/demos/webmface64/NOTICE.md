# webmface64 (static build)

Built from the webmface64 project with `npm run build:embed` and copied here as-is;
see `web/README.md` for how to update it.

Bundled third-party code:

- three.js — MIT License, https://github.com/mrdoob/three.js
- lil-gui — MIT License, https://github.com/georgealways/lil-gui
- MediaPipe Tasks Vision runtime and Face Landmarker model (`mediapipe/`) — Apache License 2.0,
  https://github.com/google-ai-edge/mediapipe

`models/mario-head/` is a head model extracted from Super Mario 64. It is © Nintendo, is
not covered by any of the licenses above, and is included here only for this demo.
