# plymouth-3dboot web viewer (static build)

The plymouth-3dboot viewer compiled to WebAssembly with Emscripten (`just viewer-web` in
the 3dboot repo; output of `target/web/`), copied here as-is. See `web/README.md` for how
to update it.

- Built from the 3dboot working tree at commit `2cd7df4` plus uncommitted changes
  (build of 2026-10-02 23:11).
